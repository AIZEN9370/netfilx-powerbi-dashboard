# 🎬 Netflix Power BI Dashboard

## 📊 Project Overview

This project is an interactive **Netflix Data Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard analyzes Netflix-related datasets and provides insights into content genres, languages, IMDb ratings, countries, runtime, box office performance, and awards.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze Netflix content data
- Explore different movie and show genres
- Analyze content based on language
- Evaluate IMDb ratings
- Visualize Netflix content by country
- Analyze runtime distribution
- Explore box office performance
- Analyze awards received

---

## 🛠️ Tools & Technologies Used

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Analysis
- Data Visualization

---

## 📂 Datasets Used

The dashboard uses multiple Netflix-related datasets, including:

- Netflix Titles
- Netflix Originals
- Netflix Rotten Tomatoes, Metacritic, IMDb Data

---

## 📈 Dashboard Features

The Power BI dashboard includes the following visualizations:

### 🎭 Genre Analysis
Analyze Netflix content based on different genres.

### 🌐 Language Analysis
Visualize the distribution of Netflix content across different languages.

### ⭐ IMDb Score Analysis
Analyze and evaluate IMDb ratings of Netflix content.

### 🌍 Country Analysis
Explore Netflix content from different countries using geographical visualization.

### ⏱️ Runtime Analysis
Analyze the distribution of content based on runtime.

### 💰 Box Office Analysis
Visualize box office-related data and performance.

### 🏆 Awards Analysis
Analyze awards received by movies and shows.

## 📊 Key Insights

This dashboard helps users:

- Identify popular content genres
- Understand language distribution
- Analyze IMDb ratings
- Explore geographical content distribution
- Compare runtime categories
- Analyze box office data
